# MySmartHome

En konsolapplikation i Java 25 för att hantera smarta enheter i hemmet – lampor, kameror och element.
Projektet är en skoluppgift på Chas Academy (kravspecifikation: [`SPECIFICATION.md`](SPECIFICATION.md)).

## Funktioner

- Lägga till och ta bort enheter (Lamp, Camera, Radiator)
- Aktivera och avaktivera enheter – kameran har även en extra lampa som kan styras separat
- Söka på namn (stigande, fallande eller osorterat) och på id
- Lista alla enheter sorterade på id
- Visa aktuellt tillstånd för en enhet
- Felhantering med egna exceptions som har tydliga meddelanden vid felaktig inmatning
- En inbyggd demonstration av all funktionalitet

## Krav

- Java 25 (JDK)
- Ingen egen Gradle-installation behövs – projektet använder Gradle Wrapper (Gradle 9.8.0)

## Starta applikationen

Alla kommandon körs från projektets rotkatalog. På Windows används `gradlew.bat` i stället för `./gradlew`.

| Kommando                              | Beskrivning                               |
|---------------------------------------|-------------------------------------------|
| `./gradlew run`                       | Startar appen med ett tomt hem            |
| `./gradlew run --args=with_fake_repo` | Startar appen med sex färdiga testenheter |
| `./gradlew run --args=demo`           | Kör demonstrationen och avslutar          |

Testerna körs automatiskt innan appen startar och måste vara godkända.

### Köra som JAR

```bash
./gradlew build
java -jar build/libs/mysmarthome-1.0-SNAPSHOT.jar
java -jar build/libs/mysmarthome-1.0-SNAPSHOT.jar with_fake_repo
java -jar build/libs/mysmarthome-1.0-SNAPSHOT.jar demo
```

## Demonstration

Demonstrationen visar steg för steg, med en kort paus mellan varje steg:

1. Skapande av flera enheter
2. Aktivering och avaktivering
3. Sökning på namn
4. Visa alla enheter
5. Felhantering (avaktivera en redan avstängd enhet, dubblettnamn, okänt id)

Den kan startas på tre sätt:

- `./gradlew run --args=demo`
- Menyval **5. Demonstration** i huvudmenyn (bekräfta med `YES`)
- Klassen `se.chasacademy.fredrikhallstrom.mysmarthome.demomysmarthome.Main`

Demonstrationen använder ett eget repository, så den påverkar inte enheter du själv har lagt till och kan köras flera
gånger.

## Tester

```bash
./gradlew test
```

Testrapporten hamnar i `build/reports/tests/test/index.html`.

Testerna är i största möjliga mån skrivna med JUnit Jupiter och Mockito enligt TDD (Red → Green → Refactor). Varje publik metod med logik i
`model`, `repository`, `service` och `util` testas med normalfall, gränsfall och felfall. Tid testas med en fast klocka 
med `Clock.fixed(...)`.

## Projektstruktur

```
se.chasacademy.fredrikhallstrom.mysmarthome
├── model             Enheterna (SmartEquipment, Lamp, Camera, Radiator) och små gränssnitt för förmågor
│                     (Lightable, Heatable, Recordable, ExtraStateControllable)
├── repository        Lagring av enheter bakom SmartEquipmentRepositoryInterface (InMemoryRepository)
├── service           Affärslogik: skapa, validera, ta bort och hämta enheter
│   ├── handler       Ändra och läsa av tillstånd på enheter
│   └── search        Sökning på namn och id
├── ui                Konsolmenyer (BaseForMenu och en undermeny per funktion)
├── exception         Egna exceptions för alla felfall
├── util              Inmatningsvalidering och tidsformatering
└── demomysmarthome   Demonstrationen och testdata (FakeRepoInit)
```

## Design

- **SOLID:** modellerna innehåller bara data och tillstånd, logiken ligger i services. Beroenden (repository, `Clock`)
  injiceras via konstruktorn och koden arbetar mot gränssnitt.
- **Nya enhetstyper** läggs till i `SmartEquipmentType` utan att befintlig kod behöver ändras.
- **Tid** sparas i UTC via en injicerad `Clock` och visas i systemets tidszon.
